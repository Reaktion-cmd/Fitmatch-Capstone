# Encuesta de validación del problema - FitMatch

## Objetivo

Validar si las personas que practican deportes de manera amateur presentan dificultades para encontrar compañeros, rivales u organizar actividades deportivas.

## Método

Se diseñó una encuesta mediante Google Forms orientada a potenciales usuarios de FitMatch.

La encuesta considera aspectos como:

- Edad.
- Hábitos deportivos.
- Deportes practicados.
- Frecuencia de práctica.
- Dificultades para encontrar compañeros.
- Problemas de coordinación.
- Cancelaciones de último minuto.
- Herramientas utilizadas actualmente.
- Criterios importantes para encontrar compañeros deportivos.
- Interés en eventos deportivos cercanos.
