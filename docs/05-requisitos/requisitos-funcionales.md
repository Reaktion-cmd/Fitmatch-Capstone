# Requisitos Funcionales - FitMatch

## 1. Propósito

El presente documento define los requisitos funcionales iniciales de FitMatch, es decir, las acciones y capacidades que deberá ofrecer el sistema a sus usuarios.

Los requisitos podrán ser actualizados durante el desarrollo según los resultados de validación, prioridades del Product Backlog y alcance definitivo del MVP.

---

## 2. Requisitos Funcionales

### RF-01 - Registro de usuario

El sistema deberá permitir que una persona pueda crear una cuenta para utilizar FitMatch.

### RF-02 - Inicio de sesión

El sistema deberá permitir que un usuario registrado pueda iniciar sesión utilizando sus credenciales.

### RF-03 - Cierre de sesión

El sistema deberá permitir que el usuario pueda cerrar su sesión de manera segura.

### RF-04 - Creación de perfil deportivo

El sistema deberá permitir que el usuario cree un perfil deportivo con información básica relevante para el uso de FitMatch.

### RF-05 - Edición de perfil

El sistema deberá permitir que el usuario modifique la información de su perfil.

### RF-06 - Selección de deportes

El sistema deberá permitir que el usuario seleccione uno o más deportes de interés.

### RF-07 - Definición de nivel deportivo

El sistema deberá permitir que el usuario indique su nivel deportivo de manera declarativa.

### RF-08 - Búsqueda de usuarios

El sistema deberá permitir buscar otros usuarios considerando criterios relacionados con la actividad deportiva.

### RF-09 - Recomendación de usuarios compatibles

El sistema deberá permitir recomendar usuarios utilizando criterios como deporte, nivel y ubicación.

La lógica definitiva de compatibilidad será definida durante el desarrollo del proyecto.

### RF-10 - Visualización de perfiles

El sistema deberá permitir visualizar información relevante del perfil deportivo de otros usuarios.

### RF-11 - Creación de eventos deportivos

El sistema deberá permitir que un usuario cree un evento deportivo indicando información como deporte, fecha, hora, ubicación y cupos disponibles.

### RF-12 - Visualización de eventos

El sistema deberá permitir visualizar los eventos deportivos disponibles.

### RF-13 - Detalle de evento

El sistema deberá permitir consultar la información de un evento deportivo antes de participar.

### RF-14 - Participación en eventos

El sistema deberá permitir que un usuario pueda unirse a un evento que tenga cupos disponibles.

### RF-15 - Gestión de cupos

El sistema deberá actualizar la disponibilidad de cupos de acuerdo con la participación de los usuarios.

### RF-16 - Confirmación de asistencia

El sistema deberá permitir que un participante confirme su asistencia a una actividad deportiva.

### RF-17 - Cancelación de participación

El sistema deberá permitir que un usuario pueda cancelar su participación en un evento.

### RF-18 - Gestión de eventos creados

El sistema deberá permitir que el creador de un evento consulte y administre la información básica de la actividad creada.

---

## 3. Requisitos funcionales considerados para etapas posteriores

Las siguientes funcionalidades podrán desarrollarse posteriormente si el avance del proyecto lo permite:

### RF-19 - Chat directo

El sistema podrá permitir comunicación directa entre usuarios.

### RF-20 - Chat grupal

El sistema podrá permitir comunicación entre los participantes de un evento deportivo.

### RF-21 - Notificaciones

El sistema podrá enviar notificaciones relacionadas con invitaciones, confirmaciones, cancelaciones, recordatorios o mensajes.

### RF-22 - Lista de espera

El sistema podrá gestionar una lista de espera cuando un evento alcance el máximo de participantes.

### RF-23 - Reemplazo de participantes

El sistema podrá facilitar el ingreso de un nuevo participante cuando se produzca una cancelación.
